# 경제 용어 관계 사전 프로젝트 계획

## 프로젝트 개요

경제 용어 간의 비례, 반비례, 상관관계를 Cytoscape를 활용하여 시각화하는 웹 애플리케이션입니다.

## 목표

- 경제 용어 간의 관계를 직관적인 그래프로 시각화
- 사용자가 용어와 관계를 쉽게 탐색할 수 있는 인터페이스 제공
- 관계 유형(비례/반비례/상관관계)을 색상으로 구분하여 표현

## 기술 스택

- **프론트엔드**: React 18 + TypeScript
- **빌드 도구**: Vite
- **스타일링**: Tailwind CSS
- **그래프 시각화**: Cytoscape

## 현재 구현 상태

### 완료된 기능
- ✅ 기본 프로젝트 구조 설정
- ✅ Cytoscape 통합
- ✅ 경제 용어 데이터 구조 정의
- ✅ 관계 그래프 시각화 컴포넌트
- ✅ 노드/엣지 클릭 시 상세 정보 툴팁
- ✅ 관계 유형별 색상 구분 (비례/반비례/상관관계)
- ✅ 인터랙티브 그래프 탐색 (드래그, 줌)

### 데이터 구조
- **용어 (Term)**: id, name, description, category
- **관계 (Relation)**: id, term1Id, term2Id, type, description
- **관계 유형**: proportional(비례), inverse(반비례), correlation(상관관계)
- **참고**: 한 노드에 여러 엣지가 연결될 수 있음 (다중 관계 지원)

## 향후 개선 사항

### 단기 (필수)
- [ ] 그래프 레이아웃 최적화
- [ ] 노드 색상 조정 (연결 수에 따라 색상으로 표현)
- [ ] 반응형 디자인 개선
- [ ] 용어 검색 기능
  - 드롭다운으로 용어 검색 및 선택
  - 선택된 용어의 노드만 크기가 커지도록 하여 선택 상태를 시각적으로 표현
- [ ] 그래프 애니메이션
  - 그래프 간의 움직임 애니메이션
  - 노드/엣지 클릭 시 선택되는 애니메이션
  - 검색으로 노드 선택 시 크기 변화 애니메이션

### 중기 (선택)
- [ ] 카테고리별 색상 구분 (노드 색상에 카테고리 정보 반영)
- [ ] 그래프 레이아웃 알고리즘 선택 옵션
- [ ] 데이터 내보내기/가져오기 기능
- [ ] 엣지 다중 연결 시각화 개선 (한 노드에 여러 엣지가 연결된 경우)

### 장기 (고려)
- [ ] 특정 용어 중심으로 그래프 필터링
- [ ] 관계 히스토리/타임라인
- [ ] 고급 애니메이션 효과 (트랜지션, 페이드 등)

## 개발 가이드

### 데이터 추가 방법
1. `src/data/terms.json` 파일 수정
2. `terms` 배열에 새 용어 추가
3. `relations` 배열에 새 관계 추가

### 스타일 수정
- 그래프 스타일: `src/components/RelationGraph.tsx`의 `style` 배열 수정
- 레이아웃 설정: `layout` 객체의 파라미터 조정

## 참고사항

- 빌드에 포함되지 않는 파일들은 `docs/` 디렉토리에 보관
- 데이터는 현재 JSON 파일로 관리 (향후 데이터베이스 연동 고려 가능)
- Cytoscape 레이아웃 알고리즘은 `cose` 사용 중 (변경 가능)
- **상세 구현 계획은 `docs/implementation-plan.md` 참조**
- **현재 아키텍처 및 구현 상태는 `docs/now.md` 참조**
- **테스트 가이드 및 구현 상태 체크리스트는 `docs/test.md` 참조**
