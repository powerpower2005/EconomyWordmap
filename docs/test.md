## 실행 방법

### 1. 사전 요구사항
- Node.js 18 이상 설치 필요 (최신 버전 권장)
- npm 패키지 매니저 (Node.js 설치 시 자동 포함)

**Node.js 설치 방법:**
1. https://nodejs.org/ 접속
2. **최신 버전 (Current)** 다운로드 및 설치
   - 현재 최신: Node.js 25.x
   - 또는 최신 LTS: Node.js 24.x (더 안정적)
3. 터미널 재시작 후 `node --version`으로 확인

### 2. 의존성 설치
```bash
npm install
```

### 3. 개발 서버 실행
```bash
npm run dev
```

개발 서버가 실행되면 브라우저에서 `http://localhost:5173` (또는 표시된 포트)로 접속합니다.

**참고:** 자세한 실행 가이드는 `docs/quick-test.md` 참조

### 4. 프로덕션 빌드
```bash
npm run build
```

빌드 결과물은 `dist/` 디렉토리에 생성됩니다.

### 5. 빌드 결과물 미리보기
```bash
npm run preview
```

## 문제 해결

### 개발 서버가 실행되지 않는 경우
1. Node.js 버전 확인: `node --version` (18 이상 권장)
2. `node_modules` 삭제 후 재설치: `rm -rf node_modules && npm install`
3. 포트 충돌 확인: 다른 포트 사용 `npm run dev -- --port 3000`

### 그래프가 표시되지 않는 경우
1. 브라우저 콘솔에서 에러 확인
2. Cytoscape 라이브러리 로드 확인
3. 데이터 파일(`src/data/terms.json`) 경로 확인

### 스타일이 적용되지 않는 경우
1. Tailwind CSS 빌드 확인
2. `index.css`에서 `@tailwind` 지시어 확인
3. 브라우저 캐시 삭제
