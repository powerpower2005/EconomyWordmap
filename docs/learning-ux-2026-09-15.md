# 경제 학습 UI/UX 개선

## 변경

- 학습을 첫 화면으로 유지하면서 질문 중심 주제 목록, 첫 이야기 추천, 예상 읽기 시간으로 진입점을 정리했다.
- 학습 제목·연결 용어·명제 검색, 주제 분류, 저장한 용어/명제가 포함된 이야기 필터를 제공한다.
- 본문은 연속된 글로 유지하며 데스크톱 목차, 모바일 접이식 목차, 읽던 파트 자동 저장과 이어읽기를 추가했다.
- 대화/설명 모드와 큰 글씨 설정을 브라우저에 저장한다. 저장소 오류가 읽기를 막지 않도록 처리했다.
- 용어와 명제는 접힌 상태에서 시작하고, 명제의 성립 조건과 예외는 넓은 화면에서 나란히 배치한다.
- 학습에서 관계도·명제·시장 화면으로 이동한 경우 복귀 버튼과 화면별 스크롤 위치를 제공한다.
- 헤더와 색상, 여백을 정리하고 본문을 가리던 고정 피드백 버튼을 헤더로 옮겼다.
- 처음부터 관계도 화면을 마운트하지 않고 방문할 때 불러온다. 키보드 포커스, 버튼 접근성 이름, 터치 영역을 보강했다.

## 검증

- `npm run build`: 통과. 전체 데이터가 포함된 초기 번들의 크기 경고는 남아 있다.
- `npm run validate-data`: 통과. 이야기 간 의도적인 용어 재사용 경고는 유지한다.
- `node scripts/check-learning-render.js`: 118개 본문 렌더링 검사 통과.
- `node scripts/check-learning-ui.js`: 11개 이야기, 검색 이름, 이어읽기 표시, 손상되거나 차단된 저장소 검사 통과.
- 실제 브라우저 1280×900, 390×844에서 목록과 본문 확인.
- 검색 결과 없음 및 초기화, 주식과 위험 필터(2개), 용어 저장 및 저장 주제 필터, 대화/설명 전환, 큰 글씨, 목차 이동, 관계도 이동과 학습 복귀 확인.
- 새로고침 후 이어읽기로 저장된 두 번째 파트에 복귀하고 설명 모드가 유지됨을 확인.
- 모바일 본문과 큰 글씨에서 문서 가로 넘침 없음. 검사 시 브라우저 오류 로그 없음.

## 범위

읽던 위치는 파트 단위로 저장하며 기기 간 동기화는 하지 않는다. 경제 콘텐츠의 사실관계와 기존 관계도 자체의 시각화 알고리즘은 이번 UI 변경 범위에 포함하지 않았다.
