# 학습·관계·명제 점검 — 2026-09-15

## 결론

기존 데이터의 양보다 **학습 질문으로 이어지는 경로와 설명의 밀도**가 문제였다. 전체 용어 492개는 하나의 연결망에 속했지만 기존 학습은 7개 섹션·36개 파트였고, 명제 253개 중 95개가 학습에 연결되지 않았다. 거시 대시보드의 `part-cycles`에는 용어 47개·명제 25개가 몰려 있었다.

이번 변경은 기존 개념을 재사용해 **4개 섹션·12개 파트**를 추가한다. 각 파트는 같은 사실을 다루는 대화·설명 본문과 접힌 용어·명제 참조로 구성했다. 새 용어는 만들지 않았다.

## 고친 오류와 연결

- 구매력 계산: 점심 10,000원 → 10,500원은 가격 +5%, 해당 상품 기준 구매력 약 −4.8%다. 기존의 −33%를 대화·설명 모두 수정했다.
- 손익분기 인플레이션: 동일 만기의 명목국채 수익률에서 TIPS 수익률을 빼는 순서로 고쳤다.
- 달러 자산: 환헤지 없는 달러 강세는 원화 환산가치를 높인다. 기존의 반대 설명을 수정하고 복리 환산식을 추가했다.
- 기간프리미엄: 미래 **명목** 단기금리 기대에 기대인플레이션을 다시 더하던 중복 계산을 용어·`r1127`에서 수정했다.
- 듀레이션: 맥컬리 듀레이션과 수정듀레이션을 구분하고 가격 변화 근사의 가정을 명시했다.
- 베타·알파: 수익 자체와 민감도, 지수 초과수익과 위험 조정 초과성과를 구별했다. `p106`에서도 적극 운용의 초과성과를 보장하는 듯한 서술을 수정했다.
- 손실 회피: 고정된 두 배 법칙처럼 읽히던 용어·`p41`을 수정했다.
- 대공황: 미국 1933년 실업률을 약 25%로 수정했다. 기존 37%는 학습 두 본문과 연결 명제 `p159`의 예시에서 제거했다.
- 가상 사건: 날짜가 특정되지 않은 CPI 발표 주간을 실제 일정처럼 적었던 부분은 가상 장면으로 명시했다.
- 대화 몰입: 다른 섹션·파트를 안내하던 대사를 인물 사이의 설명으로 바꿨다. 이자 지출과 국방비 비교만으로 재정 우위를 단정하지 않도록 보완했다.
- `r1017`: 수요견인·비용상승 인플레이션은 동시에 발생할 수 있어 `inverse`를 `correlation`으로 수정했다.
- `r837`·`r1115`: 같은 신용창조–M2 쌍을 `r837`로 통합했다. `r1115`를 삭제하고 명제의 참조도 옮겼다. 의미는 유지했으며 삭제 전 내용은 Git 이력에서 복구 가능하다.

## 점검 범위와 남은 과제

모든 YAML 항목을 대상으로 ID·참조·중복 관계쌍·연결 성분·고립 용어·학습 커버리지·대화 형식의 구조 검사를 했다. 새 학습과 연결한 핵심 메커니즘은 본문·용어·명제를 대조했다. **전체 1,310개 관계의 경제적 주장과 모든 역사적 수치를 각각 외부 출처로 검증한 것은 아니다.**

잔여 학습 미연결 명제는 73개다. 미연결을 곧바로 오류로 보지는 않는다. 기본 명제의 심화·유사 주장, 이론·역사, 추가적인 재정·산업·국제경제 논제가 포함되어 있다. 중요도 5 이상인데 학습에 직접 연결되지 않은 용어는 32개이며 상세 목록은 검사 명령으로 확인한다.

우선순위는 다음과 같다.

1. **기존 거시 대시보드의 과밀 해소:** `part-cycles`의 실물 지표를 기존 `sec-real-economy`의 고용·소비·생산·주택 이야기와 재편집한다. 이번에는 기존 참조를 대거 옮기지 않았다.
2. **재정과 기업 이익의 전달:** 자동안정화·증세·보조금·생산유발계수, `p8`, `p29`, `p54`, `p199`, `p200`을 묶을 수 있다.
3. **환율·대외대차대조표:** 금리차, 실질실효환율, 외환보유액, 자본 유출, `p55`, `p210`, `p228`을 중심으로 기존 무역 섹션의 밀도를 나눌 수 있다.
4. **산업 공급망과 지정학:** 수출통제·구리·희토류·배터리와 `p73`, `p89`, `p98`–`p100`의 실적 전달을 보강할 수 있다.
5. **이론·역사:** 학파를 단순 양분하는 기존 한 파트를 수요 관리·기대·시장 실패라는 질문으로 확장하고 기존 역사 수치와 사건 묘사를 별도로 대조할 필요가 있다.

`AGENTS.md`의 “학습 섹션 한 개만 제공”, “earnings 용어 없음”이라는 Known gaps 메모는 실제 데이터보다 오래되었다. 이번 검토는 현재 YAML을 기준으로 했다.

## 검증 방법

```bash
node scripts/audit-learning.js
node scripts/check-learning-render.js
node build-data.js
npm run validate-data
npm run build
```

`audit-learning.js`는 읽기 전용이다. 깨진 참조·중복·조건부 명제 누락은 실패로, 과밀 파트·미연결 항목은 개선 후보로 출력한다. 기존 `validate-data`는 여러 섹션의 동일 용어 사용을 경고하지만 투자 질문이 다를 때의 재사용은 의도적이다.

최종 결과: 구조 검사 오류 0, 새 네 섹션 내부 고립 용어 0, 118개 본문 렌더링 검사 통과, 데이터 검증 통과, TypeScript·Vite 전체 빌드 통과. Vite의 대용량 번들 경고와 오래된 Browserslist 데이터 경고는 남아 있다. 샌드박스의 Vite 설정 접근 제한으로 처음 빌드가 실패했으며 승인된 일반 권한 실행에서 완료했다.

브라우저 기반 화면 검증은 현재 Codex의 in-app 브라우저 연결이 발견되지 않아 수행하지 못했다. UI 레이아웃을 확인했다고 간주하지 않는다. 커밋·푸시는 수행하지 않는다. 변경 이력 날짜는 커밋 뒤 다시 빌드해야 완전히 반영된다.
