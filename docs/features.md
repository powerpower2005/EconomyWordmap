## 그래프 시각화

### 기본 기능

- **노드 클릭**: 노드를 클릭하면 해당 용어의 상세 정보가 모달로 표시됩니다.
  - 그래프가 자동으로 해당 노드로 이동하고 확대됩니다 (줌 레벨: 1.2)
  - 모달에는 용어 이름, 설명, 카테고리, 관계 정보가 표시됩니다

- **엣지 클릭**: 노드 사이의 연결선을 클릭하면 해당 관계의 정보가 툴팁으로 표시됩니다.
  - 관계 타입, 설명, 강도 정보 표시

- **그래프 조작**:
  - 노드 드래그: 노드를 드래그하여 그래프를 이동할 수 있습니다
  - 마우스 휠: 확대/축소 가능
  - 물리 시뮬레이션: 노드가 부드럽게 움직이며 연결 관계를 유지합니다

### 초기 설정

- **초기 줌 레벨**: 2.0 (그래프가 적당히 확대된 상태로 표시)
- **레이아웃**: Cose 레이아웃 사용
- **노드 크기**: 150x150px
- **엣지 최대 길이**: 12,500px
- **이상적 엣지 길이**: 1,200px

### 추천 단어

- **위치**: 그래프 위에 표시되는 카드 형태의 섹션
- **제목**: "추천 단어"
- **설명**: "가장 관계가 많은 단어 TOP 10개"
- **기준**: 엣지(관계) 수가 많은 상위 10개 용어를 자동으로 선정
- **표시 방식**: 파란색 배경의 태그 형태로 표시
- **상호작용**: 추천 단어를 클릭하면 해당 노드로 이동하고 상세 정보가 표시됩니다
  - 그래프가 자동으로 해당 노드로 이동 및 확대 (줌 레벨: 1.5)
  - 상세 정보 모달 표시

### 랜덤 단어

- **위치**: 추천 단어 섹션 아래에 표시되는 카드 형태의 섹션
- **제목**: "랜덤 단어"
- **설명**: "추천 단어를 제외한 랜덤 10개"
- **선정 방식**: 추천 단어(TOP 10)를 제외한 나머지 용어 중에서 무작위로 10개 선택
- **표시 방식**: 보라색 배경의 태그 형태로 표시 (추천 단어와 시각적으로 구분)
- **상호작용**: 랜덤 단어를 클릭하면 해당 노드로 이동하고 상세 정보가 표시됩니다
  - 그래프가 자동으로 해당 노드로 이동 및 확대 (줌 레벨: 1.5)
  - 상세 정보 모달 표시

## 용어 검색

### 검색 기능

- **검색 위치**: 통합 섹션의 "용어 검색" 탭
- **검색 범위**:
  - 용어 이름
  - 용어 설명
  - 카테고리
- **검색 방식**: 부분 일치 검색 (대소문자 구분 없음)

### 검색 결과

- **드롭다운 표시**: 검색어 입력 시 실시간으로 검색 결과가 드롭다운으로 표시됩니다
- **최대 결과 수**: 20개 (필터링 시)
- **결과 정보**: 각 결과에 용어 이름, 카테고리, 주식시장 중요도(별), 설명이 표시됩니다
- **결과 선택**: 검색 결과를 클릭하면 그래프에서 해당 노드로 이동하고 상세 정보가 표시됩니다

## 검색 필터

### 필터 기능

- **위치**: 용어 검색 탭 내부
- **토글**: "필터 보기/숨기기" 버튼으로 필터 섹션 표시/숨김
- **필터 종류**:
  - 주식시장 중요도 필터
  - 카테고리 필터

### 주식시장 중요도 필터

- **범위**: 1-10점
- **표시 방식**: 별(★☆) + 점수
  - 1점: ☆
  - 2점: ★
  - 3점: ★☆
  - 4점: ★★
  - 5점: ★★☆
  - ...
  - 10점: ★★★★★
- **선택 방식**: 다중 선택 가능
- **표시**: 선택된 필터는 노란색 배경으로 하이라이트

### 카테고리 필터

- **카테고리 목록**: 7개 카테고리
  - 거시경제
  - 국제경제
  - 금융
  - 통화
  - 통화정책
  - 정부
  - 원자재
- **선택 방식**: 다중 선택 가능
- **표시**: 선택된 필터는 파란색 배경으로 하이라이트

### 활성 필터 표시

- **위치**: 검색창 위
- **표시 방식**: 배지 형태로 표시
- **제거**: 각 배지의 X 버튼으로 개별 제거 가능
- **일괄 초기화**: "모든 필터 초기화" 버튼으로 한번에 제거

### 필터 조합

- **검색어 + 필터**: 검색어와 필터를 조합하여 정밀 검색 가능
- **다중 필터**: 중요도와 카테고리를 동시에 적용 가능
- **예시**:
  - "10점, 9점" + "거시경제" = 거시경제 분야의 가장 중요한 용어
  - "금융" 카테고리만 선택 = 금융 관련 모든 용어
  - "인플레이션" 검색 + "8점 이상" = 인플레이션 관련 중요 용어

## 주식시장 중요도

### 중요도 시스템

- **척도**: 1-10점 (10점이 가장 중요)
- **기준**: 주식시장에 미치는 영향력
- **표시**: 별(★☆) 형태로 시각화
  - 작은별 2개 = 큰별 1개
  - 예: 3점 = ★☆, 5점 = ★★☆, 10점 = ★★★★★

### 중요도 표시 위치

- **노드 상세 모달**: 노드를 클릭했을 때 카테고리와 함께 표시
- **검색 결과**: 각 검색 결과에 별로 표시
- **주식시장 중요도 탭**: 중요도별로 그룹화하여 표시

### 주식시장 중요도 탭

- **위치**: 통합 섹션의 "주식시장 중요도" 탭
- **정렬**: 10점부터 1점까지 내림차순
- **그룹 표시**: 각 중요도별로 용어를 그룹화
  - 별 표시 + 점수 표시
  - 해당 중요도의 용어 개수 표시
  - 클릭하면 용어 목록 펼침
- **상호작용**: 용어를 클릭하면 그래프에서 해당 노드로 이동

### 중요도 등급별 용어 예시

- **10점 (★★★★★)**: 금리, 기준금리, 인플레이션
- **9점 (★★★★☆)**: GDP, 실질GDP, CPI, 기대인플레이션, 양적완화
- **8점 (★★★★)**: 실질금리, 실업률, 환율, 소비, 투자, 재정정책
- **7점 (★★★☆)**: 명목GDP, 통화량, 은행, 가계부채, 금, 구리
- **6점 (★★★)**: M2, 자기자본비율, 레버리지비율, 건전성규제
- **5점 이하**: 기술적 지표 및 세부 개념들

## 용어 인덱스

### 인덱스 구조

- **위치**: 통합 섹션의 "용어 인덱스" 탭
- **탭 구분**: 한글/영문 탭으로 구분

### 한글 인덱스

- **분류 기준**: 자음별 분류 (쌍자음 제외)
  - 기본 자음: ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅅ, ㅇ, ㅈ, ㅊ, ㅋ, ㅌ, ㅍ, ㅎ
  - 쌍자음(ㄲ, ㄸ, ㅃ, ㅆ, ㅉ)은 기본 자음으로 매핑
- **표시 방식**: 각 자음 섹션을 클릭하면 해당하는 용어 목록이 표시됩니다
- **정렬**: 가나다순 정렬

### 영문 인덱스

- **분류 기준**: 알파벳별 분류 (A-Z)
- **영문 추출 방식**:
  - 용어 이름이 영문으로 시작하는 경우
  - 한글 용어 이름에 괄호 안 영어가 병기된 경우 (예: "인플레이션 (Inflation)" → "I"로 인덱싱)
- **표시 방식**: 각 알파벳 섹션을 클릭하면 해당하는 용어 목록이 표시됩니다
- **정렬**: 알파벳순 정렬

### 인덱스 UI

- **크기 최적화**: 컴팩트한 디자인으로 공간 효율성 향상
- **스크롤**: 최대 높이 96 (max-h-96)로 제한하여 스크롤 가능
- **그리드 레이아웃**: 반응형 그리드 (2-5열)

## UI/UX 개선

### 통합 섹션 구조

- **구조**: 사용방법, 용어 검색, 용어 인덱스를 하나의 상위 섹션으로 통합
- **탭 전환**: 상위 탭으로 각 기능을 전환할 수 있어 공간 효율성 향상
- **기본 탭**: "용어 검색" 탭이 기본으로 선택됨

### 크기 최적화

- **통계 카드**: 등록된 용어, 관계 정의 통계를 작은 인라인 형태로 표시
- **인덱스 섹션**: 컴팩트한 디자인으로 크기 축소
  - 제목: text-xl → text-lg
  - 탭 버튼: 작은 패딩과 폰트 크기
  - 섹션 간격: space-y-4 → space-y-2
  - 용어 목록: 작은 패딩과 폰트 크기

### 범례 및 카테고리

- **위치**: 그래프 아래에 표시
- **관계 타입 색상**: 비례(파란색), 반비례(빨간색), 상관관계(보라색)
- **카테고리 색상**: 노드 테두리 색상으로 카테고리 구분
  - 거시경제: #3b82f6 (파란색)
  - 국제경제: #14b8a6 (청록색)
  - 금융: #10b981 (초록색)
  - 통화: #f59e0b (주황색)
  - 통화정책: #8b5cf6 (보라색)
  - 정부: #64748b (회색)
  - 원자재: #d97706 (갈색)

## 카테고리 시스템

### 카테고리 통합 (2024.01 업데이트)

기존 15개의 세분화된 카테고리를 7개로 통합하여 관리 효율성과 사용자 경험을 개선했습니다.

### 통합 전 (15개)
- 거시경제
- 국제경제
- 금리
- 금리정책
- 금융
- 금융규제
- 금융시장
- 금융안정
- 정부
- 중앙은행
- 채권
- 통화
- 통화금융
- 통화정책

### 통합 후 (7개)

1. **거시경제** (13개 용어)
   - GDP, 인플레이션, 실업률, 소비, 투자 등

2. **국제경제** (1개 용어)
   - 환율 등

3. **금융** (8개 용어)
   - 은행, 신용창조, 자기자본비율 등
   - 통합된 하위 카테고리: 금융규제, 금융안정, 통화금융

4. **통화** (5개 용어)
   - 본원통화, M2, 지급준비금 등

5. **통화정책** (5개 용어)
   - 기준금리, 양적완화, QT 등
   - 통합된 하위 카테고리: 금리정책

6. **정부** (1개 용어)
   - 재정정책 등

7. **원자재** (5개 용어)
   - 금, 은, 구리, 철광석, 천연가스

### 통합 이유

- **중복 제거**: 금리/금리정책, 금융/금융규제/금융안정 등 유사 카테고리 통합
- **명확성 향상**: 카테고리 수를 줄여 사용자가 쉽게 이해
- **관리 효율성**: 용어 추가 시 카테고리 선택이 더 명확해짐
- **검색 개선**: 필터 UI가 더 간결하고 사용하기 쉬워짐

## 관계 탐색

### 관계 정보 표시

- **모달 내 관계 섹션**:
  - "영향을 주는 관계": 해당 용어가 다른 용어에 영향을 주는 관계
  - "영향을 받는 관계": 다른 용어가 해당 용어에 영향을 주는 관계

### 관계 단어 클릭

- **클릭 가능한 관계 단어**: 모달에서 관계가 있는 단어가 파란색 버튼으로 표시됩니다
- **클릭 효과**: 관계 단어를 클릭하면 해당 용어의 상세 정보로 이동합니다
  - 그래프에서 해당 노드로 이동 및 확대
  - 상세 정보 모달 표시
- **연속 탐색**: 이를 통해 관련 용어들을 연속적으로 탐색할 수 있습니다

### 양방향 관계

- **표시 방식**: 양방향 화살표(⇄)로 표시
- **설명**: 양방향 관계는 두 용어가 서로 영향을 주고받는 관계입니다
- **역방향 정보**: 양방향 관계의 경우 역방향 관계 타입과 설명도 표시됩니다

## 기술적 구현

### 주요 컴포넌트

- `RelationGraph.tsx`: 그래프 시각화 및 상호작용 처리
- `Home.tsx`: 메인 페이지, 검색, 인덱스, 가이드 UI
- `dataLoader.ts`: 데이터 로딩 및 인덱스 생성 함수

### 주요 함수

- `getKoreanIndex()`: 한글 인덱스 생성
- `getEnglishIndex()`: 영문 인덱스 생성
- `searchTerms()`: 용어 검색
- `getKoreanInitial()`: 한글 초성 추출 (쌍자음 매핑 포함)
- `getEnglishInitial()`: 영문 첫 글자 추출 (괄호 안 영어 포함)
- `getStarRating()`: 주식시장 중요도를 별(★☆)로 변환
- `filterTermsByImportance()`: 중요도별 용어 필터링

### 상태 관리

- `mainTab`: 통합 섹션의 상위 탭 상태 (guide/search/index/importance)
- `activeTab`: 인덱스의 한글/영문 탭 상태
- `expandedSection`: 펼쳐진 인덱스 섹션
- `searchQuery`: 검색어
- `searchResults`: 검색 결과
- `selectedNode`: 선택된 노드 (모달 표시용)
- `recommendedTerms`: 추천 단어 목록 (관계 수 상위 10개)
- `randomTerms`: 랜덤 단어 목록 (추천 단어 제외 10개)
- `selectedImportance`: 주식시장 중요도 탭에서 선택된 중요도
- `selectedImportanceFilters`: 검색 필터에서 선택된 중요도 목록
- `selectedCategoryFilters`: 검색 필터에서 선택된 카테고리 목록
- `showFilters`: 필터 섹션 표시 여부

## 피드백 기능

### 피드백 버튼

- **위치**: 화면 최상단 우측에 고정된 버튼
- **디자인**: 
  - 파란색-보라색 그라데이션 배경
  - 그림자 효과 및 호버 시 확대 애니메이션
  - 크기: `px-6 py-3`, 텍스트 크기: `text-base`
- **기능**: 클릭 시 피드백 폼 모달이 열립니다

### 피드백 폼

- **필수 입력 항목**:
  - 제목: 피드백의 제목을 입력
  - 내용: 최소 50자 이상의 피드백 내용
- **검증**:
  - 내용은 실시간으로 글자 수를 확인하며, 50자 미만일 경우 오류 메시지 표시
  - 제목과 내용이 모두 입력되어야 전송 가능
- **전송 방식**: GitHub Issues 새 이슈 페이지로 이동 (제목·본문 미리 채움)
- **제출**: GitHub 로그인 후 사용자가 이슈를 직접 등록 (저장소에 공개)
